\# PicturesSquad Client System



Project setup for PicturesSquad Studio Nepal / NaniBabu Photo Studio.



\## Technologies



\- Frontend: React with Vite and JavaScript

\- Backend: Node.js with Express.js

\- Database: PostgreSQL

\- Package manager: npm



\## Project Structure



\- `frontend/` - React and Vite application

\- `backend/` - Express API server



\## Start the Frontend



```cmd

cd frontend

npm run dev
